## Project Description

The Smart Library Occupancy & Resource Intelligence System is a data-driven machine learning platform designed to predict library occupancy and resource demand.

The system helps students identify available seats and alternative study areas during peak hours. It also helps library administrators understand resource demand and improve resource utilization.

## Features

- Library occupancy prediction
- Seat availability estimation
- Peak-hour detection
- Resource demand prediction
- Alternative resource recommendation
- Study area recommendation
- Historical occupancy analysis
- Interactive Streamlit dashboard
- Machine learning pipeline

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Streamlit
- GitHub

## Machine Learning Models

XGBoost regression models are used for:

1. Occupancy Prediction
2. Resource Demand Prediction
